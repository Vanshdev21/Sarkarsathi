# 🇮🇳 SarkarSathi

> Your AI Companion for Government Services.

SarkarSathi is an AI-powered multilingual assistant that helps citizens discover government schemes, understand eligibility, identify required documents, and navigate application processes.

## 🚀 Features

- 🔎 Government scheme discovery
- ✅ AI-powered eligibility guidance
- 📄 Document checklist
- 🎙️ Voice interaction
- 🇮🇳 Hindi + English support
- 🤖 AI-powered explanations
- 🔐 Trust-first information retrieval
